# Changelog

All notable changes to eVoca are documented here.

## [0.1.0] - 2026-08-29

### Added

- Windows-first launcher workflow with global `Ctrl + Space` hotkey.
- Reusable AI configurations with provider/model settings.
- OpenAI-compatible and Ollama providers.
- Local SQLite execution history.
- Screenshot capture and preview workflow.
- System-tray operation.
- Local credential storage abstraction with Windows Credential Manager support.
- Settings and full backup/restore flows with credential references instead of raw API keys.
- Security coverage for backup traversal and credential/header handling.
- Public contribution and security documentation.
- Automated CI/release configuration for Windows builds and checksum generation.
